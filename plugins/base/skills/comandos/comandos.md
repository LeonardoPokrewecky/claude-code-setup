# Comandos do pacote (gerado)

> Gerado por `scripts/gerar-docs.ps1` a partir das skills. Não editar à mão. Lido pela skill `/comandos`.
> `(também automática)`: o Claude também usa a skill sozinho quando a tarefa pede.

## Plugin `base`

| Comando | O que faz |
|---|---|
| `/adr` | Registra uma decisão técnica na seção "Decisões" do CLAUDE.md do projeto |
| `/alterar-dados` | Planeja e executa alteração de dados em banco |
| `/autenticacao-e-sessao` | Decide e revisa o modelo de autenticação e sessão |
| `/automacao-e2e` | Planeja e escreve testes de interface ponta a ponta estáveis |
| `/blueprint` | Planejamento obrigatório antes de qualquer alteração não trivial (também automática) |
| `/comandos` | Lista os comandos do pacote com um resumo de cada um |
| `/componentes-e-estados` | Projeta componentes de interface reutilizáveis com variantes, estados de… |
| `/comunicacao-de-status` | Redige relatório de andamento objetivo e fiel ao que aconteceu |
| `/criar-testes` | Gera testes para código sem cobertura, seguindo o framework e o padrão do… |
| `/deploy-checklist` | Checklist de deploy |
| `/desenvolvimento-de-interfaces` | Coordena trabalho de frontend (também automática) |
| `/divida` | Registra e lista dívida técnica |
| `/endurecimento-de-infraestrutura` | Auditoria somente leitura para reduzir a superfície de ataque da infraestrutura |
| `/entrega-sem-pendencia` | Checklist de fechamento antes de declarar uma tarefa pronta |
| `/env-guide` | Guia do ambiente Claude Code deste pacote (também automática) |
| `/escolha-de-banco-e-capacidade` | Ajuda a escolher o tipo de banco e a dimensionar capacidade |
| `/explicar` | Mapa de um módulo, fluxo ou projeto para onboarding |
| `/gestao-de-segredos` | Auditoria e procedimento de gestão de segredos |
| `/historias-de-usuario` | Escreve histórias de usuário |
| `/inspecao-visual` | Abre a aplicação no navegador com Playwright e inspeciona as rotas relevantes… |
| `/integracoes` | Projeta integrações com sistemas externos |
| `/laudo-de-evidencia` | Gera um laudo de validação |
| `/layout-responsivo` | Projeta e verifica layouts responsivos de 320 px a telas largas |
| `/lgpd-audit` | Auditoria LGPD completa e somente leitura de um app |
| `/limpar-codigo` | Relatório de código morto, duplicado, imports/variáveis sem uso e… |
| `/medir-antes-depois` | Mede o comportamento ANTES e DEPOIS de uma correção, no mesmo ambiente e com o… |
| `/metricas-de-produto` | Define métricas de produto |
| `/modelagem-dados` | Modelagem de dados para relacional ou documental |
| `/plano-migracao` | Plano de upgrade de versão |
| `/postmortem` | Monta o post-mortem de um incidente ou bug sério |
| `/preparar-pr` | Prepara o texto do PR a partir do diff |
| `/priorizacao` | Ordena uma lista de itens |
| `/project-bootstrap` | Prepara um projeto para o ambiente Claude Code (também automática) |
| `/referencias-visuais` | Pesquisa referências de interface sob demanda |
| `/regressao-e-smoke` | Define e mantém uma verificação rápida pós-publicação |
| `/responder-revisao` | Trata os comentários de revisão de um PR |
| `/resposta-a-incidente` | Roteiro de resposta a incidente em andamento |
| `/revisar` | Revisão somente leitura por lentes |
| `/session-handoff` | Gera um resumo de passagem de bastão quando uma tarefa vai continuar em outra… |
| `/sistema-de-design` | Define ou audita o sistema de design de uma interface |
| `/teste-de-api` | Valida endpoints de uma API |
